# Staunen über die Schöpfung (Baukasten)

Stunden-Baukasten für Katholische Religion, 8. Klasse Mittelschule (KR8, Lernbereich 3).
Live: https://fhe86.github.io/schoepfung/

- index.html, style.css, app.js: Seite mit Weg-Diagramm
- data.js: alle Phasen, Methoden und Fertig-Wege (hier Inhalte ändern)
- material/: druckbare Arbeitsblätter und Karten

## Folien und Bilder
- folien.html: Beamer-Folien (alle Methoden: #alle, eigener Weg: #weg=a1,b3,-,d1,e1), Inhalte in slides-data.js
- img/: freie Bilder (Public Domain oder CC), Nachweis in img/quellen.json und img/quellen.html
